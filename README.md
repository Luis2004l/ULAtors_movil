# ULAtors móvil

Aplicación móvil para técnicos de ULAtors. Incluye inicio de sesión y autenticación contra la API.

## Ejecutar

Instala las dependencias con `pnpm install` y ejecuta la aplicación con `pnpm start`.

## API

El inicio de sesión envía las credenciales a `POST /token`. Configura `EXPO_PUBLIC_API_URL` para usar una URL base distinta a la predeterminada.
